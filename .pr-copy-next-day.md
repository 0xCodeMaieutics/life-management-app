## Summary

Right-click a **day plan item** → **Copy on the next day** duplicates it on tomorrow’s **day plan** (creates that **day plan** if missing). The source item is unchanged; the copy is incomplete and has no **reminder**.

```mermaid
sequenceDiagram
    participant User
    participant DayPlanItemRow
    participant copyDayPlanItemToNextDay
    participant DB
    User->>DayPlanItemRow: Copy on the next day
    DayPlanItemRow->>copyDayPlanItemToNextDay: itemId
    copyDayPlanItemToNextDay->>DB: load item + plan date
    copyDayPlanItemToNextDay->>DB: ensure day plan for date + 1
    copyDayPlanItemToNextDay->>DB: insert day plan item (completed false)
    copyDayPlanItemToNextDay-->>DayPlanItemRow: ok
```

## Evidence

- **Before:** Context menu had no copy action; next day’s plan could not receive a duplicate from the current item.
- **After:** `pnpm typecheck` passes.
